# ⚡ CloudGPT Mobile — Наша Собственная Обученная Нейросеть

**CloudGPT** — автономная нейросетевая модель нового поколения с поддержкой компьютерного зрения (Vision), живого двустороннего голосового помощника, генерации изображений в 8K и глубокими знаниями в программировании, реверс-инжиниринге и системной архитектуре.

---

## 📱 Android Приложение (APK)
* **Готовый установщик:** [`CloudGPT-Mobile.apk`](./CloudGPT-Mobile.apk) *(197 КБ)*
* **Особенности:**
  * Полноэкранный нативный интерфейс приложения.
  * Прямая съемка фото с камеры телефона для мгновенного Vision-анализа.
  * Двусторонний голосовой ассистент с анимированной сферой и озвучкой ответов.
  * Настоящая авторизация через Google аккаунт.
  * Подписан v1, v2, v3 схемами подписи (действителен до 2056 года, без ошибок «пакет недействителен»).
  * Для пересборки APK: запустите `python build_apk.py`.

---

## 🌐 Развертывание на Vercel (vercel.app)
Проект полностью готов для мгновенного деплоя на Vercel:
1. Загрузите репозиторий на GitHub.
2. В панели [Vercel](https://vercel.com/) нажмите **Add New Project** и выберите ваш репозиторий.
3. Vercel автоматически подхватит конфигурацию из [`vercel.json`](./vercel.json), соберёт статику из папки `public/` и развернёт серверлесс бэкенд из `api/index.py`.
4. Либо выполните в консоли:
   ```bash
   vercel deploy --prod
   ```
